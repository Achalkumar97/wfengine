# @wfengine/ui

React components for authoring workflows: **`WorkflowCanvas`** (React Flow), **`exportWorkflowDefinition`**, palette metadata.

- Peer dependencies: **`react`**, **`react-dom`** (≥ 18).
- Imports **`reactflow/dist/style.css`** internally on the canvas component.

Used by **`apps/studio`**; does not call the server by itself — wire **`Run workflow`** in your app when needed.

See the [repository README](../../README.md).
